# Fishing

Fishing-App mit aktuellen Pegel-, Wetter- und Wasserqualitätsdaten.

## Live-Test

Die Seite wird nach jedem Push auf `main`, bei manueller Ausführung und automatisch
alle sechs Stunden über GitHub Pages aktualisiert:

https://degeneuropean.github.io/Fishing.emil.dev1/

Der Workflow lädt vor jeder Veröffentlichung die neuesten Wasserwerte. Pegel- und
Wetterdaten werden beim Öffnen der Seite direkt von den jeweiligen Live-APIs geladen.
